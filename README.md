# quantum-credit-mqfs

An honest three-way benchmark of classical vs quantum machine learning on real
credit-risk data, with finance-aware evaluation.

MQFS (Mediterranean Quantitative Finance Society) working paper project —
Nicolò Angileri, 2026.

**No quantum advantage is claimed.** Results tables are generated from actual
runs (`results/*.json`); this README is finalized by `experiments/render_tables.py`.
